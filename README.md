# Fleet Fuel Consumption Analysis

## Project Overview

This project analyzes fleet fuel consumption data using Power BI to identify fuel usage patterns, vehicle efficiency, and cost performance.

## Tools Used

- Power BI
- Excel/CSV
- Data Visualization
- Data Cleaning

## Dashboard Features

- Total Fuel Consumption Analysis
- Vehicle-wise Fuel Usage
- Fuel Consumption Trends
- Fuel Efficiency Comparison
- Fuel Cost Distribution
- Vehicle Performance Summary

## Dataset

The dataset contains information about:
- Vehicle ID
- Distance Travelled
- Fuel Consumption
- Fuel Cost
- Fuel Efficiency
